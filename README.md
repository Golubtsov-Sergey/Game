🎮 Memory Card Game

A classic interactive Memory Card Game built with vanilla JavaScript, HTML5, and CSS3.
The goal is to find all matching pairs of cards by flipping them over.

🛠 Tech Stack

Core: HTML5, CSS3, JavaScript (ES6+).

Styling: Custom CSS with Flexbox/Grid layouts.

Responsive Design: Fully adaptive for desktop, tablet, and mobile devices (media.css).

Assets: Custom fonts and optimized images.

✨ Features

Game Logic: Random card shuffling algorithm on every restart.

Interaction: Smooth CSS animations for card flipping.

Win/Loss States: Logic to track matched pairs and end-game scenarios.

Responsive UI: The game board adjusts automatically to the screen size (Mobile-first approach).

💡 What I Learned

During the development of this project, I focused on:

DOM Manipulation: Handling user clicks and updating the UI dynamically without libraries.

Game State Management: Tracking variables for flipped cards, lock board state, and matched pairs.

CSS Animations: Using transform: rotateY for realistic card flip effects.

Responsive Web Design: Ensuring the game grid looks good on any device using Media Queries.
